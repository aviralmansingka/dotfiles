 L1 · The machine manager
 L0's box opened one level: its boundary services — private gRPC, webapi, provider registry,
 cluster reconcile, SSH + BMC ops and the boot server — sit in the Machine manager box, while the
 control plane, humans, providers and machines stay outside it.

 L1b · The machine side
 The fleet end of the same system. Bare-metal machines run the machine-agent, which registers and
 heartbeats into public gRPC inside the manager's box; the River queue uploads diagnostics to S3
 and webapi confirms actions in Slack, both outside. The fleet drives these outward relations.

 L2 · Inside — queue and dispatch
 Inside the box, first slice: requests land on the River queue, which dispatches provision jobs
 to the provider registry, audit work to SSH + BMC ops and diagnostic events to the janitor; the
 janitor proposes actions back to webapi. L2b carries the state writes this slice leaves out.

 L2b · Inside — the state writes

 queue, machine rows from private gRPC, machine state from public gRPC heartbeats and cluster
 state from the reconcile loop. Same box, same manager; only the state edges are drawn here.
