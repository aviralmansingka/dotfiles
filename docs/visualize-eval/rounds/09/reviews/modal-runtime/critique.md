## Findings, blockers and correction candidates

- **High defect — labelled pair ownership:** use unambiguous local labels or explicit leaders; reproduce a human-readable check, not just checker ownership counts. Candidate/spec and renderer label placement are both plausible correction targets.
- **High defect — tier hues:** name-derived orchestration and storage colors collide; make source-tier membership visible in distinct hues or one non-boxed tier label line. This is a renderer/color-assignment and skill verification issue, not a call for group boxes.
- **Medium defects — source coverage and recipe:** restore `filesystem` to the daemon relation and `input` to the worker relation; order fan ports according to the source listing and ensure both co-viewed pair labels have unambiguous owners.
- **Medium workflow defect:** record a `label_slot` attempt for the v5 shortened-label tree or provide an applicable measured constraint before shortening; analogous larger-shape failures do not prove this exact case.
- **Low cosmetic UI observation:** the pinned v5 header truncates `it` from `q quit`; no node border is damaged. Not independently a border-integrity failure.
- **Renderer limitation, not a proven blocker:** recorded alternate shapes show adjacent same-rank label-slot routing failures, but the review does not establish that the required semantics are impossible by all supported layouts. No unresolved capability blocker is proven. No missing evidence prevents a decision.
