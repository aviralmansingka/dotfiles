## Limits this proposal cannot fix

Instructions cannot add a bus/junction declaration or independent live-dot count
to the frozen renderer. They also cannot add semantic-group color metadata or
make the label router reserve all required visual space. Those changes belong
in a separately tested renderer baseline, not an uncredited skill-only revision.

The color rule remains the frozen rule: related source concepts need related
hues and appropriate proximity. Global per-node color stability across views is
not a separate new gate. The proposal prevents misleading claims about what the
position-based palette represents; it does not silently amend the rubric.

## Why there is no rerun

The frozen stop rule permits stopping at an unsupported required capability.
GB300's explicit shared trunk and the manager's one-live-dot request reach that
boundary. Another skill-only full sweep cannot demonstrate those capabilities.
A rerun would consume eight new generators and eight judges without clearing
that known prerequisite. No improvement or two-revision convergence is claimed.

If renderer support is added, freeze the new binary and source as a new baseline.
Then test all eight cases with fresh DeepSeek generators and separate Astra judges.
Keep the same dataset, target size, and rubric. Preserve strict attempt limits;
round01 includes over-budget exploration and is not a clean bounded comparison.
