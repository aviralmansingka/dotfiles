Proposed language

Precise names keep session truth separate from surface behavior.

Discussion vocabulary; persist after approval.

Durable process identity

Herdr-managed process, PTY, transcript, and session reference. Never called a Neovim or terminal session.

One view of a session

A Sidekick or terminal client connected to an Agent Session with declared surface behavior.

Time-bounded live grant

Herdr's permission for one attachment to send input and own interactive mouse routing.

The one live owner

The attachment currently allowed to mutate the TUI. There may also be no holder.

Safe concurrent viewer

An attachment that follows status and snapshots without input or mouse ownership.

Resolved owner map

The inspectable result saying who owns history, selection, clipboard, opener, paste, input, and mouse.

Small external interface

Three lifecycle operations; existing transcript reads stay intact.

Illustrative names, not frozen commands.

launch(profile)
→ Agent Session

Creates or resumes durable agent state with a stable session policy.

open(session, surface)
→ Attachment + Plan

Registers the surface and returns either the live lease or observer status.

release(attachment)
→ Released

Relinquishes ownership and unregisters the attachment on hide, close, or detach.

agent read
→ Snapshot

Remains the canonical history interface; no duplicate transcript protocol is required.

Heartbeat renewal belongs inside the attachment implementation. Callers should not manually choreograph liveness timers.

Lease lifecycle

Safe concurrency without stranded takeover.

A healthy holder is never silently displaced.

Attachment Lease state machineopen · renew · observe · release · expire
At most one live-input holder; zero holders is valid.
Any number of observers may read snapshots safely.
A second surface never steals a healthy lease silently.
Hide, close, detach, and explicit switch release immediately.
Crash or liveness loss expires ownership after a bounded interval.
Switching surfaces never changes Agent Session identity.
History exists once in Herdr; surface buffers are projections.
Every open returns an inspectable effective Capability Plan.

Scenario outcomes

Concrete transitions the design must survive.

Same agent; ownership moves, state does not.

Launch in Neovim

Sidekick gets the first lease

The Workspace Tab chooses the session profile. Sidekick opens as nvim, receives the plan, displays live PTY output, and uses Herdr snapshots for history mode.

OUTCOME · perfect Neovim-native history without a second session
Continue in terminal

Same session, new holder

After Sidekick releases, Herdr terminal mode acquires the lease. Copy mode, OSC52, opener, and terminal paste own the surface experience.

OUTCOME · no restart, no transcript fork
Open both

One holder, one observer

The current holder stays interactive. The other surface follows status and snapshots and may request transfer.

OUTCOME · concurrency without surprise takeover
Neovim crashes

Ownership self-heals

The heartbeat stops; the bounded lease expires. Terminal mode can acquire while the agent process, conversation, and transcript survive.

OUTCOME · recovery without manual pane surgery
No surface open

The agent still completes

Zero holders is normal. Herdr retains output and marks completion; opening either surface later shows the same final transcript.

OUTCOME · background work is independent of viewers

Decisions and risks to discuss

The proposal is concrete; these choices shape implementation.

Exact timeout values should be tested, not guessed.

Recommended

No implicit takeover

A second surface observes by default. Transfer is deliberate; force requires explicit intent or a stale holder.

Recommended

Release on Sidekick hide

Hidden UI should not retain live-input ownership. The Agent Session continues independently.

Discuss

Transfer authority

Can a healthy holder reject forever, or does explicit user force always win after confirmation?

Measure

Lease timeout

Choose heartbeat and expiry intervals from real Neovim stalls and Herdr behavior, not aesthetics.

Phase 2 dependency

Owning Herdr source

The installed 0.8 CLI exposes only attach plus --takeover. Lease semantics require work in the owning Herdr repository, but Phase 1 can freeze the contract now.

Verification risk

History fidelity

Real Pi and Codex sessions must prove resize, ANSI replay, links, copy-without-controls, and return-to-live behavior.

Out of scope: rewriting Pi/Codex rendering, duplicating transcript storage in Neovim, building a semantic event protocol, or making Sidekick a session authority.
