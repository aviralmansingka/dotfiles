Release decision · notification service

Ship in stages. Advance only on health.

Use a staggered rollout to contain failures: internal users first, then 10%, 50%, and 100%. Each cohort earns promotion by keeping error rate and delivery latency within their existing thresholds for one full observation window.

Failure rule

The response order is fixed so investigation cannot prolong exposure.

Contain first; investigate second.

01 · automatic action

Pause on either regression

A breach in error rate or delivery latency is sufficient. The rollout stops without waiting for both signals to fail.

02 · containment action

Roll back before investigation

Return the active cohort to its prior state first. Root-cause analysis begins only after the current exposure has been contained.
